# AI House Price Predictor

This is a student AI portfolio project that predicts house prices using a machine learning regression model built from scratch in Python.

The project does not rely on scikit-learn or external machine learning libraries. It implements the main ML workflow manually, including dataset generation, feature engineering, feature scaling, model training, evaluation, prediction intervals, and model saving/loading.

## Features

- Synthetic housing dataset generation
- Train/test split
- 5-fold cross-validation
- Feature engineering
- Standard feature scaling
- Linear regression trained with gradient descent
- L2 regularization
- MAE, RMSE, MAPE, and R-squared metrics
- Baseline model comparison
- Prediction confidence range
- Feature contribution explanation
- Interactive console menu
- Save and load model as JSON
